STEELHAVEN — an original tactical FPS built with three.js. Night has fallen on a walled training compound and five waves of hostiles are inbound. Pointer-lock mouse aim, WASD movement with sprint and jump, hitscan rifle with headshot bonus and reload, two enemy types across 5 escalating waves, a live radar, and procedural WebAudio sound effects. No build step and no assets: everything is generated in code.

## Run it

```sh
node main.ts            # writes the playable game to $MAKEFUN_OUTPUT_DIR (default /output)
npm run serve           # or play in place: python http server on :8080, open index.html
npm test                # logic tests
```

Controls: click to lock the pointer, WASD to move, Shift to sprint, Space to jump, mouse to aim, click to fire, R to reload.
